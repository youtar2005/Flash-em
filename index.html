    Turn a JSON file into a deck

    Add a file, paste JSON, or try the sample deck. Each card needs a front and a back. Question/answer and term/definition work too, and cards can have a hint and tags. Multiple choice cards add an options list and an answer.

    {
  "title": "Spanish basics",
  "images": { "cat": { "src": "data:image/webp;base64,...", "caption": "A cat" } },
  "cards": [
    { "front": "hola", "back": "hello", "hint": "greeting", "tags": ["phrases"] },
    { "question": "gato", "answer": "cat", "image": "cat" },
    { "front": "Which word means ‘dog’?", "options": ["gato", "perro", "pájaro"], "answer": "perro" }
  ]
}

    Images go on the back of the card and are referenced by name from the top-level images list. Pictures must be embedded as data URLs, because web addresses are blocked on published pages.
